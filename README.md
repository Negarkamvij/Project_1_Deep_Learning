# NYC Yellow Taxi EDA — CS672 Project 1

Start with `Taxi_Project_1.ipynb`. It contains explanations, starter code, and writing prompts. It is not a completed or executed analysis.

1. Open the notebook in Jupyter or your chosen notebook environment.
2. Set up compatible dependencies using the TFDV installation guide linked inside.
3. Download March and May 2020 Yellow Taxi Parquet files from NYC TLC into `data/` beside the notebook.
4. Run cells in order, investigate the data, and write your findings.
5. Submit the single notebook with its outputs. January comparison is optional extra credit.

Large datasets and local environments are excluded from version control.
